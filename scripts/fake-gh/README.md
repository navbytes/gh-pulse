# fake-gh

A stand-in `gh` that answers from `fixtures/*.json` (synthetic users, orgs, repos, PRs, issues, notifications; no real data).
It exists so the global-home screenshots in the README can be regenerated by anyone without exposing an account.

- Offline: Python standard library only, no sockets, never reads `~/.config/gh`.
- Read-only: writes (non-GET `gh api`, GraphQL mutations, `pr`/`issue` edits, `workflow run`, ...) are refused with exit 1 and
  appended to `$FAKE_GH_LOG/writes.log`; every call goes to `$FAKE_GH_LOG/calls.log` (default: the system temp dir).
- Answers: `search prs|issues` (qualifiers `review-requested/author/assignee/mentions/involves:@me`, `is:`, `repo:`, `org:`),
  `api graphql` (repo browser, startup batch, comments, review threads), `api user|user/orgs|notifications|rate_limit`,
  `repo view`, `pr view|checks|diff`. Anything else is `[]`.
- Timestamps are relative to now (`age_h`, `age_m` in the fixtures), so "2h ago" stays plausible.

`scripts/screenshots.py --fake` puts this directory first on `PATH` for a throwaway `HOME`, config and state seeded from
`fixtures/config.toml` (favorites, hidden repos) and `fixtures/recent.json`. To try it by hand:

```sh
PATH="$PWD/scripts/fake-gh:$PATH" GH_CONFIG_DIR=$(mktemp -d) target/release/gh-tui --start global
```
