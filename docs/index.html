DESIGNED FOR TRUST

Power you can
see before you use.

gh-tui shells out to the GitHub CLI for authentication and actions. The confirmation popup previews the command before a write, and L opens the command log.

gh-tui / confirm action

Run this command? [y yes, n/Esc no]

gh pr review 5 -R owner/repo --approve

START HERE / QUICK SETUP

Install it.
Keep moving.

gh-tui is a GitHub CLI extension. Authenticate with gh, install once, then launch from any directory.

Prebuilt for macOS (arm64, amd64) and Linux (arm64, amd64; glibc 2.35+). Windows is unsupported.
